# Baidu Netdisk

Baidu Netdisk (百度网盘) is a cloud storage service. This backend uses Baidu's
xPan OAuth2 and file APIs, following the same application-directory model as
the official [bdpan-storage](https://github.com/baidu-netdisk/bdpan-storage)
integration.

Paths are specified as `remote:path`, for example `remote:directory/file`.

## Application directory

Baidu restricts an application to its own directory under
`/apps/{app_name}/`. Rclone treats that directory as the top level of the
remote and rejects paths that attempt to escape it.

The built-in bdpan OAuth credentials use `/apps/bdpan/`. When using your own
OAuth client ID and secret, set the advanced `app_name` option to the app name
registered for those credentials. A mismatch normally results in Baidu API
error `-6` (user not authorized).

## Configuration

Run:

```console
rclone config
```

Create a new remote, select `Baidu Netdisk (百度网盘)`, and complete the OAuth
authorization in your browser. The built-in client ID and secret can be used
by leaving both fields blank.

To use your own application, create one through the
[Baidu Netdisk developer platform](https://pan.baidu.com/union/), then enter
its OAuth client ID, client secret, and application name in the advanced
configuration.

See the [remote setup docs](/remote_setup/) when authorizing a machine without
an internet-connected browser.

After configuration, common commands include:

```console
rclone lsd remote:
rclone copy /home/source remote:backup
rclone sync /home/source remote:backup
rclone about remote:
```

## Uploads

Baidu's multipart protocol requires MD5 hashes before uploading blocks, so
uploads use two passes. Seekable sources are read twice. Non-seekable or
unknown-size sources are first spooled to a temporary file; sufficient local
temporary disk space is therefore required. Blocks are uploaded sequentially
in 4 MiB chunks.

## Modification times and hashes

Baidu reports server modification times but does not support setting them, so
rclone treats modification times as unsupported for comparisons.

The MD5 hash is supported when Baidu returns a valid 32-character hexadecimal
value. Baidu may return a non-standard value for some small files; in that
case rclone reports the hash as unavailable.

## Deletion

`rclone rmdir` removes only an empty directory. Use normal rclone safety
controls such as `--dry-run` or `--interactive` before commands that delete
files.
